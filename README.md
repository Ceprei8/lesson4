# Dostaffkin — урок 3 (эталон для сверки)

Эталон домашнего задания к уроку 3 интенсива Itlogia «Frontend: Start» —
«Вёрстка всего сайта». Страницы «Оформление доставки» и «Отслеживание доставки».

> ⚠️ Это папка **учителя**: используется только для сверки с вашей работой.
> Не копируйте код отсюда в сдаваемую работу — повторяйте урок своими руками,
> а сюда сверяйтесь, если что-то не получается.

## Структура

```
index.html              — главная страница (день 2) + ссылки навигации
order.html              — страница «Оформление доставки»
track.html              — страница «Отслеживание доставки»
styles/
  base.css              — база (день 2) + общие стили полей формы
  base_adaptive.css     — адаптив базы
  order.css             — стили страницы оформления
  order_adaptive.css    — адаптив оформления (767/420px)
  track.css             — стили страницы отслеживания
  track_adaptive.css    — адаптив отслеживания (767px)
fonts/                  — Roboto (Regular, Medium, Bold)
images/                 — картинки (см. images/README.md)
```

## Отличия HTML от «заметок дня 3»

В эталоне, в отличие от чистовых заметок, уже добавлено (это шаг «ссылки в
шапке» в конце урока):

- `index.html` — ссылки «Оформить доставку» → `order.html`,
  «Отследить посылку» → `track.html`;
- `order.html` — логотип → `index.html`, «Отследить посылку» → `track.html`,
  «Оформить доставку» остаётся `#`;
- `track.html` — логотип → `index.html`, «Оформить доставку» → `order.html`,
  «Отследить посылку» остаётся `#`.

## Запуск

Откройте `order.html` или `track.html` в браузере. Порядок подключения стилей
(сверху вниз): `base.css` → `base_adaptive.css` → файл страницы →
его адаптив.

## Сверка после вашего выполнения

Должны совпадать (по содержимому и размеру в байтах):

- `order.html`, `track.html`

- физическое наличие файлов в `images/` (не ярлыки)
