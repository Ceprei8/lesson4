# Dostaffkin — Урок 4: JavaScript (скорость доставки)

Проект интенсива Itlogia «Frontend: Start». День 4 — оживляем весь сайт
с помощью JavaScript: Яндекс-карта, расчёт маршрута и стоимости, отправка
заявки, отслеживание посылки.

## Структура

```
index.html              — главная страница
order.html              — «Оформление доставки» (карта + расчёт + заявка)
track.html              — «Отслеживание посылки» (поиск + статусы)
scripts/
  order.js              — логика страницы оформления
  track.js              — логика страницы отслеживания
styles/
  base.css, base_adaptive.css
  index.css, index_adaptive.css
  order.css, order_adaptive.css
  track.css, track_adaptive.css
images/
  order-bg.png          — фон карты на странице оформления
  track-bg.png          — фон страницы отслеживания
  main-image.png        — фото на главной
  sizes/                — карточки размеров посылок (xs…max)
  icons/                — иконки статусов и скорости (SVG)
fonts/                  — Roboto (Regular, Medium, Bold)
```

## Запуск

Откройте `index.html` в браузере. Для работы карты на `order.html` нужен
доступ к Яндекс.Картам (ключ JavaScript API уже подключён в `order.html`).

## Порядок подключения стилей

В каждом HTML (сверху вниз): `base.css` → `base_adaptive.css` →
стили страницы → адаптив страницы.

## Функционал дня 4

- построение маршрута на Яндекс-карте по адресам «Откуда → Куда»;
- расчёт расстояния, срока доставки и тарифа (зависит от размера посылки);
- отправка заявки (демо, без реального бэкенда);
- отслеживание посылки: поиск по номеру и показ четырёх статусов.
