# Картинки урока 3 — что экспортировать из макета Figma

Макет: `D:\doc\proekty\материалы\МатериалыУрокДень2\maket.fig`

## Порядок экспорта

1. Откройте `maket.fig` в Figma (desktop или web).
2. Выберите нужный слой/фрейм → правая панель → меню экспорта (`Export`) →
   формат PNG или SVG (как указано ниже) → `Export`.
3. Файл сохраните в соответствующую папку и переименуйте **строго** как ниже.

## Важные замечания

- Имена файлов — **нижний регистр** (маленькие буквы): `xs.png`, а не `XS.png`.
- Иконки статусов — обязательно **SVG** (в эталоне HTML ссылается на `.svg`),
  картинки коробок — PNG.
- Файлы должны лежать **физически**, а не быть ярлыками.
